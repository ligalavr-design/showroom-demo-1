# showroom-demo-1

A static demo page. Fake data only.

- The inquiry form is mocked in the browser: an entry is kept in this browser's localStorage and shown on the admin page. Nothing is sent anywhere.
- The admin page ("פניות") reads that local list. "טעינת דוגמאות" adds three invented entries.
- The page is marked `noindex`. No cookies, no tracking, no request to another site. The font (Rubik, OFL) is served from this site.

Build: `npm install` then `npm run build`; the output is in `dist/`.

## Sources for the page's figures

- The showroom size (about 35 to 40 square metres) is the client's own figure from a voice message of 26.10.2026. The message id is kept in the private project folder, not here.
- The ranges on the five cards are labelled examples of what is typical in the Israeli market, taken from public pages of several dealers. They are not product specifications and name no model.
